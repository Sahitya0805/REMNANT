# R E M N A N T

> **"The memories behind every order."**  
> *The World's First Commerce Memory Operating System built for Swiggy Builders Club.*

---

## 🖤 Vision & Overview

People don't remember restaurant names or receipt numbers — they remember moments:
- *"The coffee I ordered while working on my internship."*
- *"The biryani I ate after India won the IPL finals."*
- *"The cake I ordered for mom's 50th birthday."*

**REMNANT** turns every order into a permanent, searchable AI memory graph. Instead of browsing food menus, users search their life through natural language context.

---

## 🏛️ Key Capabilities

- **3D Particle Archive Void**: Visualizes commercial history as an interactive 3D WebGL particle space.
- **The Recall Curator AI**: Non-chatbot AI memory curator that reconstructs subconscious life moments (*"I found something."*).
- **Dual-Color Editorial Themes**: Parchment Beige (`#F5EFE6`) & Noir Charcoal (`#090909`).
- **Signature Orange Memory Thread**: Interactive canvas thread following cursor movements to stitch memories together.
- **1-Click Swiggy MCP Reorder**: Trigger food reorders directly from past moments.
- **Clean Swiggy MCP Data Adapter**: Decoupled Phase 1 prototype adapter ready for Phase 2 live API grants.

---

## 🛠️ Tech Stack

- **Frontend**: React + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom Editorial Design Tokens
- **Typography**: Cabinet Grotesk + Geist + IBM Plex Mono
- **3D Graphics**: Three.js (WebGL Particle Void & Topographic Contour Layers)
- **Icons**: Lucide React

## 🚀 Local Setup & Development

```bash
# Clone repository
git clone https://github.com/Sahitya0805/REMNANT.git
cd REMNANT

# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```
